후기·평점 재계산, 노쇼 신고→운영자 확정→환불, 메시지 권한, 지도자 신청→승인.

## 100명 시뮬레이션 (개발 DB)

`npm run test:simulate` — 수강생 50명 + 지도자 50명을 만들어 가입·로그인·심사·클래스 개설·예약·결제(성공/카드실패/금액위변조/결제창 이탈)·
승인/거절/미응답·취소(환불율 3단계, 지도자 취소)·완료/불참/자동완료·정산·후기·신고·메시지를 무작위로 섞어 실행한 뒤,
DB 전체를 훑어 **돈 보존(결제−환불 = 정산+진행중), 정원 초과 없음, 중복 예약 없음, 평점 = 보이는 후기 평균, 정산 금액, 페널티, 알림 도착**을 검증합니다.
`SIM_SEED=숫자`로 무작위 순서를 바꿔 반복 실행할 수 있습니다. 약 540개 항목이 모두 ✓ 이어야 합니다.

⚠️ 운영 DB에서 실행 금지

## 사람이 직접 해볼 것 (배포 주소에서, 휴대폰 + PC)

### 수강생
1. 처음 접속 → 온보딩 4단계 (각 항목 선택 없이는 "다음" 불가, "기타" 선택 시 입력 필수)
2. 홈 추천 확인 → 정렬 5종 → "거리순" 누를 때 위치 권한 요청 확인
3. 지도자 상세 → 4개 탭 → 클래스 일정 선택 → 로그인 요구 → 가입 후 예약 화면으로 복귀
4. 결제 → "승인 대기" 화면 → 예약 내역 / 알림 확인
5. 확정 후 장소가 보이는지, 취소 시 안내 금액과 실제 환불 금액 일치하는지
6. 메시지 보내기 → 지도자 계정에서 5초 내 도착

### 지도자
1. 프로필 → "명상 지도자로 활동하기" → 신청 → "심사 중" 표시
2. (관리자 승인 후) 클래스 생성 → 한 번 / 매주 반복 일정 추가 → 한국시간이 맞게 표시되는지
3. 예약 승인 / 거절(사유 전달) / 확정 후 취소 / 수업 후 완료·불참 처리
4. 정산 탭 금액 = 결제액 − 환불액 − 수수료

### 운영자
1. 지도자 심사 승인·반려(사유) → 지도자에게 알림
2. 신고 처리 → 노쇼 확정 시 환불 확인
3. 정산 "지급 완료" 기록

### 실결제 연동 후 반드시
- 실제 카드로 소액 결제 → 지도자 거절 → **카드사 앱에서 취소 내역 확인**
- 부분 환불(1일 전 취소)이 PG 관리자 화면 금액과 일치하는지
- 결제창을 중간에 닫았을 때 좌석이 15분 뒤 풀리는지
